# Xander M. Lopez

AI Software Engineer at the U.S. Department of the Treasury. Founder & Technical Lead, Zendren LLC.

[Personal site](https://xandermlopez.com) · [Zendren](https://zendren.net) · [LinkedIn](https://www.linkedin.com/in/xander-lopez)

## Featured public work

- [Algebrix CE](https://github.com/XanderXML-Bit/algebrix-ce) is a computer algebra system for the TI-84 Plus CE written in C99. [Calculator project page](https://zendren.net/projects/algebrix-ce)
- [Label Verify](https://github.com/XanderXML-Bit/label-verify) is a TypeScript and Next.js prototype that uses vision models to compare beverage labels with application fields. [Offline sample demo](https://label-verify-six.vercel.app)
- [Tooloqo](https://github.com/XanderXML-Bit/tooloqo-app) runs image, PDF, media, and text tools in the browser (TypeScript, React, Vite). [Open Tooloqo](https://tooloqo.zendren.net)
- [Mineflayer MCP](https://github.com/XanderXML-Bit/mineflayer-mcp) lets AI clients control Mineflayer bots on Minecraft servers they have permission to use (TypeScript, Zod).
- [logsift](https://github.com/XanderXML-Bit/logsift) summarizes and filters streams of Bunyan JSON logs and detects bursts without loading the whole log into memory (Rust).
- [Narratoqo](https://github.com/XanderXML-Bit/narratoqo-app) turns text into audiobooks with Kokoro and Piper voices running on your device (TypeScript, React, WebAssembly). [Open Narratoqo](https://narratoqo.vercel.app)
- [Algebrix Web](https://github.com/XanderXML-Bit/algebrix-web) is a browser calculator with exact arithmetic, graphing, matrices, and statistics (TypeScript, React, Vite). [Open the web calculator](https://algebrix.zendren.net)
- [Zendren Apify Actors](https://github.com/XanderXML-Bit/zendren-apify-actors) includes Python jobs for collecting job postings, splitting PDFs into passages with page citations, auditing sitemaps, and detecting feed changes. [Browse the actors on Apify](https://apify.com/zendren)

Languages and tools: C99, TypeScript/React, Rust, Python, and Model Context Protocol (MCP).

Most Zendren work is in private repositories. Read the [project case studies](https://zendren.net/projects).
